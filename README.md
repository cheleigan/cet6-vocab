# 六级词汇 · 四遍记忆法（小程序）

一个**纯前端**的背单词小程序：以六级词汇为目标，每天用滑动条选 **10~20** 个词，
每个单词走完整的**四遍流程**，答错自动退回上一遍；支持艾宾浩斯复习计划、学习曲线、
单词查询、错词本、词表导入导出。

- 无需安装、无需构建、无需联网（发音用系统 TTS）
- 双击 `index.html` 即可使用，手机上也能用（浏览器打开/添加到桌面）
- 数据保存在浏览器本地（localStorage），不上传任何服务器
- 项目内**不含任何密钥、Token、密码**，无需配置环境变量

## 3. 跑一遍自动化测试（可选）

```bash
cd cet6-vocab
node tests/test_app.js
```

脚本用手写的"最小 DOM 桩"在 Node 里真实加载 `app.js`，模拟点击走完整个流程，
覆盖 67 项断言：四遍流程、答错回退（第 1 遍原地 / 第 3 遍退回第 2 遍 / 拼错退回第 3 遍）、
艾宾浩斯调度与到期优先、学习曲线记账、查询、错词本、导入词表，
以及**全部 240 个词的出题质量**（每题必须 4 个选项、含正确释义、不含"意思相同或互相包含"的干扰项）。

需要 Node 14+，无任何第三方依赖。

## 3. 四遍流程（核心）

| 遍数 | 呈现内容 | 作答方式 |
| --- | --- | --- |
| 第 1 遍 · 听音辨义 | 单词 + 音标 + **自动朗读** | 从 4 个中文释义里选（3 个是形近词的释义） |
| 第 2 遍 · 图文例句 | 配图 + 例句 + 例句翻译 + 释义 | 只看，点「记住了，进入第 3 遍」 |
| 第 3 遍 · 看词选义 | **只给单词** | 从 4 个中文释义里选 |
| 第 4 遍 · 拼写 | 音标 + 中文释义 + 首字母/长度提示 | 键盘输入英文拼写后回车 |

**答错自动退回上一遍**：

| 答错位置 | 处理 |
| --- | --- |
| 第 1 遍 | 原地重来（重新出题，并给出正确释义） |
| 第 3 遍 | 退回第 2 遍，重新看配图和例句 |
| 第 4 遍 | 退回第 3 遍，重新看词选义 |

退回后答对，会顺着流程继续往下走；每个单词完整走完四遍才算"今日完成一个词"。
答错的词会进**错词本**，并降低掌握度；下次生成学习队列时错词优先出现。

## 4. 功能清单

- **每日目标**：首页滑动条选 10~20 词（任意整数），一键开始；中途退出会自动保存，下次点「继续今日学习」
- **艾宾浩斯复习计划**：每个词按 1 → 2 → 4 → 7 → 15 → 30 天安排下次复习；到期词优先进入当天队列，首页可看「今日 / 明日待复习」并一键「只复习到期词」
- **学习曲线**：首页近 14 天柱状图（每天学习词数）+ 折线（每天一次正确率），纯 SVG 手绘，无第三方库
- **智能选词**：到期复习词 > 错词 > 没背过的词 > 掌握度低的词；队列可随机打乱
- **单词查询**：右上角「🔍 查询」，支持英文前缀/模糊匹配与中文释义搜索，点开可看音标、例句、形近词、学习记录，并能「单独练一遍」
- **错词本**：右上角「📕 错词本」，按错误次数排序，可一键复习（一次最多 20 个）或清空计数
- **结算页**：完成词数、一次正确率、需复习单词数，可立即复习本次错词或再来一组
- **设置**：自动发音、在线发音（有道音频，需联网）、每日顺序随机、清空学习数据
- **导入 / 导出词表**：粘贴文本或选择本地文件导入；一键导出当前完整词库为 JSON 备份

### 复习计划说明（艾宾浩斯）

每个单词完整走完四遍后，程序给它安排下一次复习时间：

| 第几次复习 | 1 | 2 | 3 | 4 | 5 | 6 |
| --- | --- | --- | --- | --- | --- | --- |
| 间隔（天） | 1 | 2 | 4 | 7 | 15 | 30 |

- 本次学习**答错过** → 相当于没记牢，下次复习回到"1 天后"
- 当天到期的词会优先进入当天队列，首页显示「今日待复习 / 明日待复习」
- 首页「只复习到期词」可进入纯复习专场（一次最多 20 词，按到期时间排序）
- **学习曲线**记录近 14 天每天的学习词数与一次正确率；历史数据存在本地，清空学习数据会一起清除

## 5. 扩充词库到完整六级词表

内置有 240 个常见六级词，方便你先跑通流程。要换成完整词表（约 5000+ 词），两种做法：

### 方式 A：导入（推荐，不用改代码）

首页 →「导入词表」，粘贴下面这种一行一个词的文本：

```
abandon | /əˈbændən/ | v. 放弃；抛弃 | They had to abandon the plan. | 他们不得不放弃这个计划。 | 🚪
rigorous | /ˈrɪɡərəs/ | a. 严格的
notorious, /nəʊˈtɔːriəs/, a. 臭名昭著的
```

- 分隔符支持 `|`、`,`、Tab（制表符，从 Excel / WPS 复制粘贴最方便）
- 只有「单词」和「释义」也能用；音标、例句、配图缺失时自动降级
- 也支持选择 `.txt` / `.csv` / `.json` 文件，导入的词会记在本地并可「导出词库」备份

### 方式 B：直接改 `data/words.js`

在数组里追加同样格式的对象即可：

```js
{w:"rigorous", p:"/ˈrɪɡərəs/", c:"a. 严格的", e:"He is a rigorous teacher.",
 t:"他是位严厉的老师。", img:"📏", sim:["vigorous|a. 精力充沛的","ridiculous|a. 荒谬的"]}
```

字段说明：

| 字段 | 含义 | 必填 |
| --- | --- | --- |
| `w` | 单词（唯一标识，小写） | ✅ |
| `c` | 中文释义（同时作为选项文本，越短越好） | ✅ |
| `p` | 音标 | 建议 |
| `e` / `t` | 英文例句 / 例句翻译 | 建议 |
| `img` | 配图：emoji，或图片 URL（`http(s)://` 开头会渲染成图片） | 可选 |
| `sim` | 形近词，`"单词|中文释义"`，用来生成干扰选项；不够 4 个选项时程序会自动按拼写相似度补齐 | 建议 |

> 小贴士：`sim` 里写的形近词**不必**存在于词库中，因为释义直接写在 `"单词|释义"` 里。

## 6. 数据存储与重置

- 存储位置：浏览器 localStorage，键名 `cet6vocab.v1`
- 保存内容：学习进度、今日队列、错词计数、导入的词表、连续天数
- 重置：首页底部「清空学习数据」；或浏览器开发者工具里清除该站点数据
- 换电脑/换浏览器：导出词库 JSON 带走，学习进度不随文件迁移（可选后续加导入进度）

## 7. 已知限制

- **配图用的是 emoji 插画**，好处是离线可用；想要真实图片，把 `img` 换成图片 URL 即可
- **发音**：默认用系统语音库（离线可用）；勾选"在线发音"会改用有道音频，需要联网
- 语音质量取决于操作系统是否装了英文语音包（Windows：设置 → 时间和语言 → 语音）
- 学习进度存在本地，不清缓存不会丢，但没有云端同步
- 一次错一次记：连续答错会累加错误次数，掌握度最低为 0
